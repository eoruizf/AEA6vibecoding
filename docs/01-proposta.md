# 01. Proposta inicial – DogMatch
# 1. Nom de l'aplicació
   DogMatch – Plataforma per connectar propietaris de gossos
# 2. Descripció del projecte
   DogMatch és una aplicació web que permet als propietaris de gossos trobar altres propietaris interessats en una possible reproducció responsable entre les seves mascotes.
   Cada usuari podrà registrar-se, crear el perfil dels seus gossos i consultar els perfils d'altres gossos. També podrà enviar sol·licituds als propietaris i acceptar o rebutjar les sol·licituds rebudes.
# 3. Objectiu
   L'objectiu principal és crear una plataforma fàcil d'utilitzar per facilitar el contacte entre propietaris de gossos que busquen una possible parella reproductiva per a les seves mascotes.
# 4. Tipus d'usuaris
   Visitant: pot consultar informació general de l'aplicació.
   Usuari registrat: pot gestionar el seu perfil, afegir gossos, buscar altres gossos i enviar o gestionar sol·licituds.
# 5. Funcionalitats principals
   Registrar-se i iniciar sessió.
   Crear i modificar el perfil de l'usuari.
   Afegir, modificar i eliminar els perfils dels gossos.
   Buscar gossos segons la raça, el sexe i la ciutat.
   Consultar les dades i fotografies dels gossos.
   Enviar sol·licituds de reproducció a altres propietaris.
   Acceptar o rebutjar les sol·licituds rebudes.
   Consultar l'estat de les sol·licituds.
# 6. Tecnologies
   Backend: Laravel.
   Frontend: Blade, HTML, CSS i Bootstrap.
   Base de dades: MySQL.
   Control de versions: Git i GitHub.
# 7. Abast de la primera versió
   La primera versió inclourà el registre d'usuaris, la gestió dels gossos, la cerca de perfils i la gestió de sol·licituds.
   No s'inclouran pagaments, xat privat ni altres funcionalitats avançades en aquesta primera versió.
# 8. Resultat esperat
   Una aplicació web funcional, accessible mitjançant una URL i que permeti als propietaris gestionar els seus gossos i contactar amb altres propietaris.
